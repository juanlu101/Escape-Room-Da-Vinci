# El Código Da Vinci

Escape room para 4.º de ESO. Jacques Saunière, conservador del Louvre, ha muerto y ha dejado ocho acertijos. Cada uno da una coordenada (página, línea y palabra) de su cuaderno personal. Después, un cryptex de cinco anillos guarda la instrucción final, y las ocho palabras forman la frase que revela dónde está el cáliz.

Autor: Juan Luis Torralbo Muñoz.


## En clase

- El acertijo V es de sonido: conviene usar auriculares o tener el volumen alto.

- La partida se guarda sola: si alguien recarga la página, puede continuar. El reloj sigue corriendo.
- Al terminar aparece el tiempo oficial (tiempo real más penalizaciones) y un código de verificación para la clasificación.
